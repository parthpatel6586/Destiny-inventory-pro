# 📦 Installation

```bash
git clone https://github.com/yourusername/destiny-inventory-pro.git
```

```bash
cd destiny-inventory-pro
```

```bash
npm install
```

```bash
npm run dev
```

Open:

```
http://localhost:5173
```
